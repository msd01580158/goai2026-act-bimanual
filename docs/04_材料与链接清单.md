## 3. 模型检查点（服务器端，12 任务）

部署于云端评测服务器，每任务一个策略目录：

```
~/RoboDojo/XPolicyLab/policy/ACT/checkpoints/act-RoboDojo-<task>/
    └── <run>/policy_last.ckpt + dataset_stats.pkl
```

| 任务 | 检查点目录 |
|---|---|
| stack_bowls | `act-RoboDojo-stack_bowls/arx_x5-100-joint` |
| push_T | `act-RoboDojo-push_T/arx_x5-100-joint` |
| …（共 12 任务） | `act-RoboDojo-<任务>/arx_x5-100-joint` |

> 策略检查点由 `prepare_case` 按任务自动加载，不需要主办方手动指定路径。
