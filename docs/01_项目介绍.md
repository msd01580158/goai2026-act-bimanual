# 项目介绍

## 项目名称
基于 ACT 多任务策略的双臂灵巧操作智能体（GOAI 2026 · 具身未来赛道 · 赛题一）

## 参赛赛道
**具身未来（Embodied Future）—— 赛题一：通用双臂协作操作能力测试**

本方案面向赛题一，基于 X-Eval 仿真与真机一体化评测平台，围绕双臂协同操作构建可运行、可复现、可评测的具身智能方案。

## 项目概述
本项目面向**双臂复杂操作**任务，基于 **ACT（Action Chunking with Transformers）** 策略，构建了一套覆盖 **12 个双臂操作任务**的端到端智能体，并完成从数据、训练到云端评测服务的完整闭环部署。

系统采用"**本机训练 → 云端 A100 评测服务**"架构：策略在本机 GPU 上基于双臂演示数据训练，产出的检查点上传至云端评测服务器；评测系统通过公网 WebSocket 端点接入，并支持**多任务热切换**（同一端点按任务实时切换策略模型），形成"感知 → 决策 → 执行 → 验证"的完整闭环。

## 技术亮点
1. **双臂协同控制**：基于 arx_x5 双臂机器人，策略输出 14 维关节动作（左右臂 6+6 关节 + 2 夹爪），三目视觉观测（头 + 双腕相机），实现双臂协同操作。
2. **多任务单服务动态切换**：评测服务实现 `prepare_case` 钩子，评测端通过 `action_case_id`（`<任务>_case`）即可热切换策略检查点，无需重启，12 任务统一端点评测。
3. **端到端训练-部署管线**：RoboDojo 双臂演示数据（hdf5）→ 数据标准化 → ACT 行为克隆训练 → 检查点 → 云端热加载，全程自动化、可复现。
4. **动作分块 + 时序聚合**：ACT 一次推理输出 50 步动作块，配合时序聚合实现平滑高频双臂控制，降低累积误差。
5. **大规模 VLA 预研**：同步完成 RDT-1B（1B 参数视觉-语言-动作模型）在评测环境上的部署与权重验证，为从"行为克隆"升级到"具身 VLA（Vision-Language-Action）"奠定基础，符合赛道 VLA/WAM 方向。
